# Contributing to Campfire

Campfire is currently developed in a private canonical repository. This public repository is a release mirror, so unsolicited implementation pull requests are not the primary contribution path.

The most useful contributions begin with the problem:

- a concrete use case or workflow;
- a reproducible bug;
- a security or authorization constraint;
- evidence that an assumption is wrong;
- an interoperability problem with an agent harness;
- desired behavior and relevant tradeoffs;
- or a design consideration the current model misses.

Use GitHub Issues for reproducible bugs and scoped problems. Use GitHub Discussions for use cases, ideas, questions, and design exploration. Include enough context to understand the goal, observed behavior, expected behavior, constraints, and evidence without sharing credentials or private transcripts.

If implementation would help, discuss the shape of the change first. Maintainers may invite or coordinate a pull request after the behavior and boundaries are clear. A submitted pull request may be deferred or closed when the underlying product decision has not yet been made.

For vulnerabilities or sensitive security concerns, do not open a public issue. Follow [SECURITY.md](SECURITY.md).
