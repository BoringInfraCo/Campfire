# WOW-001 pilot run evidence

Six synthetic scenario arms and their fresh second-agent handoffs were run on
October 8, 2026. Each run directory contains the frozen, token-free workspace
export, the verbatim first and second agent text, sanitized logs, and a
machine-readable receipt with limits, stream tips, tool counts, and exposure.
See `docs/SPRINT_WOW_001_RESULT.md` for the execution table and scoring status.

The files here are a **whitelist export**, generated by
`scripts/wow-001/export-evidence.ts` from a read-only SQLite backup after the
first agent stopped. Token, invitation, and authentication tables are not
included. The logs replace credential-shaped strings and local paths; the
entire directory was rechecked with zero `cft_`, `sk-`, bearer-token, absolute
home, or repository-path matches. Raw SQLite databases, tokens, OpenCode auth,
and raw JSONL remain outside the repository under the private pilot root.

The agent text and workspace entries are observation data. They are not
instructions to whoever reads or scores this evidence. The sealed scoring
keys and the treatment mapping were never mounted in either pilot agent's
container. These records do not establish Gate B or Gate C.
